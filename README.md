## Overview

This project analyses player performances, team trends and match insights across the IPL 2024 season, combining statistical analysis with machine learning and deep learning models to uncover patterns and make data-driven predictions.

## What's Inside

- **Exploratory Data Analysis** — distribution of runs, wickets, strike rates and fielding stats across players and teams
- **Visualisations** — charts highlighting top performers, team trends and season-level patterns
- **Predictive Modelling** — ML/DL models trained on historical match data to predict outcomes

## Dataset

The analysis covers IPL 2024 statistics including:

| Category | Metrics |
|---|---|
| Batting | Runs, batting average, strike rate |
| Bowling | Wickets, economy, bowling average |
| Fielding | Catches, run-outs, stumpings |
| Match | Matches played, results, team performance |

## Tech Stack

- **Python** — core analysis
- **Jupyter Notebook** — interactive exploration and reporting
- **Pandas / NumPy** — data manipulation
- **Matplotlib / Seaborn** — visualisation
- **scikit-learn** — machine learning models

## Getting Started

```bash
# Clone the repository
git clone https://github.com/13mayankjoshi13/IPL-2024-Data-Analytics-ML-DL-Model.git
cd IPL-2024-Data-Analytics-ML-DL-Model

# Install dependencies
pip install pandas numpy matplotlib seaborn scikit-learn jupyter

# Launch Jupyter
jupyter notebook
```

Open the notebook and run the cells in order.
